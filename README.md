
# Project Title
Flight Management System (C Language)

## 📖 Description
A console-based project developed in C to manage flight records.  
Features include adding, viewing, searching, and deleting flight details.  
This project demonstrates file handling and structured programming concepts.

## 🛠️ Technologies Used
- C Language
- File Handling
- Visual Studio

## 🚀 Features
- Add new flight records
- View all flights
- Search flights by ID
- Delete flight records

## 📂 Project Structure
- `main.c` → Source code
- `flights.txt` → Sample data file
- `README.md` → Documentation
